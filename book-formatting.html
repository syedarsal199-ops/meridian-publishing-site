Book Formatting & Typesetting

Nothing marks a self-published book faster than its interior. Wrong margins, a default font, and widowed lines tell a reader the book was not taken seriously.

The approach

A typeset page should be invisible. If the reader notices the layout, something has gone wrong.

Print typesetting is a craft with real rules: gutter margins that account for binding, running heads that do not fight the text, and no orphan lines stranded at the top of a page. We set books the way trade publishers do.

Ebook formatting is a different discipline entirely. Reflowable text has to survive any font size on any device, which means proper semantic markup rather than hard-coded layout.

What is included

  • Print interior typeset to trade standards with correct gutters
  • Running heads, folios and front and back matter
  • Widow and orphan control throughout
  • Reflowable EPUB 3 with a working navigable table of contents
  • Kindle-specific file generation and preview testing
  • Image placement at correct print resolution
  • Files validated against each retailer before handover
